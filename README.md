### What I'm working on

**[truvan-mapper](https://github.com/VIAMRSH123/truvan-mapper)** — a LangGraph agent that maps ISO/IEC 42001 controls onto the EU AI Act and the NIST AI RMF. The agent proposes, a deterministic validator blocks citations that don't exist, a human approves every mapping, and an append-only hash-chained ledger makes the history tamper-evident. Python · LangGraph · Anthropic SDK · 12 tests.

**TFS Lead Intelligence** *(private repo — [live demo](https://tfs-lead-intelligence.vercel.app))* — an end-to-end lead platform for the family business. WhatsApp messages arrive by webhook, get parsed into structured leads, validated, de-duplicated, enriched and auto-assigned to the right sales rep by product, territory and workload. FastAPI · SQLAlchemy · JWT + role-based access · React · TypeScript · Tailwind.
